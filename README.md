
# Salesforce Sales Performance Dashboard

## Project Overview

A hands-on Salesforce CRM project focused on sales opportunity management, reporting, and performance tracking.

I built this project using Salesforce Developer Edition to understand how businesses use CRM systems to monitor sales pipelines, evaluate opportunities, and visualize sales performance.

## Business Objectives

- Track sales opportunities across different stages.
- Monitor opportunity values and expected revenue.
- Analyse sales opportunities by owner.
- Create reports to support sales performance monitoring.
- Build an interactive dashboard to present key sales information.

## Tools & Technologies

- Salesforce CRM
- Salesforce Reports
- Salesforce Dashboard Builder
- CRM Opportunity Management
- GitHub

## Reports Created

### 1. Opportunities by Owner
A report summarising sales opportunities assigned to the opportunity owner, including account names, opportunity names, stages, and financial information.

### 2. Opportunities by Stage – Revenue Summary
A report analysing opportunities across different sales stages, with a focus on opportunity amounts and expected revenue.

## Dashboard Development

Created a Salesforce Sales Performance Dashboard containing:

- Opportunities by Owner – Horizontal bar chart.
- Opportunities by Stage – Revenue summary chart.
- Opportunity Details – Tabular view of sales opportunities.

The dashboard brings multiple sales performance views together in one place.

## Skills Demonstrated

- Salesforce CRM navigation
- Opportunity management
- Report creation and configuration
- Data grouping and summarisation
- Chart configuration
- Dashboard creation
- Business reporting and data interpretation

## Project Status

Completed initial Salesforce reporting and dashboard implementation.

Further improvements will include additional CRM scenarios, pipeline analysis, and more advanced reporting.

## About This Project

This is an independent learning project built using Salesforce Developer Edition with sample CRM records. It is intended to demonstrate practical familiarity with Salesforce reporting and dashboard functionality.
